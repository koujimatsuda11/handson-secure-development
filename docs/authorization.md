# 認可制御仕様書

## 概要
- **認証方式**: AWS Cognito + カスタムミドルウェア（`CognitoAuth`）
- **ロール**: ゲスト、一般ユーザー

## RBAC（Role-Based Access Control）マトリックス

### 投稿（Posts）

| アクション/ロール | ゲスト | 一般ユーザー（自分の投稿） | 一般ユーザー（他人の投稿） |
|------------------|-------|---------------------------|---------------------------|
| **登録**          | ✗     | ✓                         | ✗                         |
| **閲覧**          | ✗     | ✓                         | ✓                         |
| **更新**          | ✗     | ✓                         | ✗                         |
| **削除**          | ✗     | ✓                         | ✗                         |


---

### いいね（Likes）

| アクション/ロール | ゲスト | 一般ユーザー（自分のいいね） | 一般ユーザー（他人のいいね） |
|------------------|-------|----------------------------|-----------------------------|
| **登録**          | ✗     | ✓                          | ✗                           |
| **閲覧**          | ✗     | ✗                          | ✗                           |
| **更新**          | ✗     | ✗                          | ✗                           |
| **削除**          | ✗     | ✓                          | ✗                           |


**注意**: いいねは「投稿に対するいいね追加/削除」の概念で、個別のいいねレコードの閲覧は想定されていない

---

### プロフィール（Users）

| アクション/ロール | ゲスト | 一般ユーザー（自分のプロフィール） | 一般ユーザー（他人のプロフィール） |
|------------------|-------|----------------------------------|---------------------------------|
| **登録**          | ✗     | -                                | -                               |
| **閲覧**          | ✗     | ✓                                | ✓                               |
| **更新**          | ✗     | ✓                                | ✗                               |
| **削除**          | ✗     | ✗                                | ✗                               |

## 認証が必要なエンドポイント

全てのAPI操作には認証が必要です（`cognitoauth` ミドルウェア適用）。
ゲストユーザーは一切のAPI操作ができません。
